CS50 Journey

03 — CS50 Journey

I started CS50x while working full-time, treating it like a second job. The goal was never just to finish — it was to understand the "why" behind every line, well enough to defend it in an interview.

Wk 0–2

Started with C

Learned how computers actually think — memory, pointers, and algorithms — by writing it all from scratch.
Wk 3–5

Algorithms & data structures

Sorting, recursion, hash tables, and the realization that "fast" means measuring wall-clock time, not just intuition.
Wk 6–7

Python & SQL

Moved up the ladder to Python and databases. Fiftyville — a SQL detective puzzle — turned out to be the most fun debugging exercise of the whole course.
Wk 8

The web (in progress)

HTML, CSS, and JavaScript — including this very site.
Next

Flask & final project

Combining everything into the Lifecycle Email Agent — my CS50x capstone.

What's next

Once I finish CS50x, I'm planning to continue with CS50P (Introduction to Programming with Python) and CS50 AI (Introduction to Artificial Intelligence with Python).
