Lifecycle Email Agent

An AI agent that drafts marketing emails and iteratively improves them — built to mirror the kind of campaign logic I used to configure manually in enterprise marketing automation platforms, except now I'm writing the system that does it.

The system uses a generator-critic self-refinement loop: a generator (gpt-4o-mini) drafts an email, and a hybrid critic — combining deterministic rule checks with an LLM-based subjective review — scores it and sends it back for revision until it passes.

  • Backend: Python, FastAPI, with Server-Sent Events (SSE) streaming
  • Frontend: Custom-built, violet/indigo theme
  • Result: The hybrid critic caught 100% of objective rule violations, versus 50–67% for a pure-LLM baseline
